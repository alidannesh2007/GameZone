🚀 اجرای پروژه
برای اجرای پروژه، ابتدا مخزن را دریافت و وارد پوشه آن شوید:
git clone YOUR_REPOSITORY_URL cd GameZone 
سپس یک محیط مجازی ایجاد کنید:
python -m venv venv 
برای فعال‌سازی محیط مجازی در ویندوز، دستور زیر را اجرا کنید:
venv\Scripts\activate 
وابستگی‌های پروژه را نصب کنید:
pip install -r requirements.txt 
Migrationهای پایگاه داده را اجرا کنید:
python manage.py migrate 
در نهایت، سرور توسعه Django را اجرا کنید:
python manage.py runserver 
پس از اجرای موفقیت‌آمیز سرور، پروژه را از طریق آدرس زیر مشاهده کنید:
http://127.0.0.1:8000/
